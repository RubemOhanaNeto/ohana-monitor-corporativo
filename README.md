# Ohana Monitor Corporativo

Sistema Integrado de Auditoria, Inteligência Fiscal, Contábil, Governança Executiva e Gestão Multissetorial.

## 🚀 Funcionalidades Principais

- **Governança & Presidência**: Visão consolidada por diretoria executiva, matriz de riscos e prazos legais.
- **Segmentação Empresarial Especializada**:
  - **Recanto da Saudade**: Cemitérios & Serviços Funerários (Lei 13.261/2016, Item 25 LC 116/2003, integração TOTVS Protheus 12 TSS/FISA/TES).
  - **Instituto GO**: Saúde e Clínicas Médicas (Item 4 LC 116/2003, DMED, TISS, retenções de IRRF/CSLL/PIS/COFINS).
  - Demais segmentos: Holding, Transportes, Indústria e Comércio.
- **Auditoria Fiscal & Reforma Tributária**:
  - Simulador do Piloto CBS/IBS (conforme diretrizes da Receita Federal e Orientação Técnica CFC nº 1/2026).
  - Gráficos de consumo e volumetria por diretoria (Recharts).
  - Logs de auditoria para chamadas e consultas às APIs fiscais.
  - Análise de consistência e conformidade preventiva de Sped.
- **Auditoria Contábil (CFC/CRCs)**:
  - NBC TG 22 (Informações por Segmento), Balanço Patrimonial segmentado, DRE e ECD/ECF.
- **Data Hub & Fontes Oficiais**:
  - Monitoramento contínuo de DOU, DOE, DJe, Receita Federal, SEFAZ, CFC e Diários Oficiais.

## 🛠️ Tecnologias Utilizadas

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Motion, Lucide Icons, Recharts.
- **Backend**: Node.js, Express, Vite, TSX.

## 📦 Como Executar Localmente

```bash
# Instalar dependências
npm install

# Iniciar o servidor de desenvolvimento
npm run dev

# Compilar para produção
npm run build
```
